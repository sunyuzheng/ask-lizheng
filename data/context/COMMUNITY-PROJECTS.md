# Community-built Projects / 社区衍生项目

这个列表收录基于 [`sunyuzheng/lizheng-open-context`](https://github.com/sunyuzheng/lizheng-open-context) 开发的公开 Skill、Agent、搜索工具和其他作品。它既是一个发现入口，也让不同实现可以互相比较：用了哪些来源、怎样处理时间和引用、选择了什么问题，以及真实使用后哪里需要继续改。

被收录表示项目通过了基本的链接、来源与权利检查，不代表立正或 Superlinear Academy 对项目质量、结论或长期维护作出背书。

## 提交你的项目

1. 公开一个可检查的代码仓库或可运行版本；
2. 说明项目如何使用本仓库，以及怎样处理引用、综合和推断；
3. 确认没有复制其他社区成员内容、私密材料或未获授权的第三方全文；
4. 在下面的表格中新增一行并提交 pull request；
5. 同时在 Superlinear 的 [Share Your Projects](https://www.superlinear.academy/c/share-your-projects?utm_source=github&utm_medium=referral&utm_campaign=lizheng_open_context) 发布项目、失败原因或复盘，再把帖子链接填进“讨论”列。

可以复制这个格式：

```markdown
| 项目名 + 公开链接 | 作者名 + 作者主页 | Skill / Agent / Tool | 一句话说明它解决什么问题，以及怎样使用本仓库 | 社区帖子链接 |
```

如果还没有完整项目，也可以先在[仓库更新讨论](https://www.superlinear.academy/c/tools/lizheng-context?utm_source=github&utm_medium=referral&utm_campaign=lizheng_open_context)里提出问题、分享原型或寻找合作者。
