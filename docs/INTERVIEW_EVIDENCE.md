# 访谈原文、归属与回答

本轮维护者明确委托系统规划、实现、验证及上线，不再逐项人工审核。范围是问问立正的访谈资料与使用机制，以及共享目录消费者的兼容；不涉及私有材料、新会员权限、模型供应商或访客信息用途的改变。

公开来源与结构化事实由 [Open Context](https://github.com/sunyuzheng/lizheng-open-context) 维护。录制版、剪辑版和文本版本分别绑定。新增五份明确公开的字幕原稿，补齐六条节目目录记录，其中一份原稿原已存在。郑昌熙、Marco Casalaina、夏淳、杨天楠四期新增自动声纹归属；英文三人对谈保留无法可靠确认的归属。声纹、音频、原始下载和处理中间件留在本机，公开文件只记录方法与hash。字幕不是逐字听校，自动归属不是人工确认。

节目说明在目录中按原发布内容保存，只参与定位，不充当发言正文。相邻字幕单元保留说话人、时间、状态与言语行为；原稿有时间重置时分开窗口，不能跨重置拼成对话。针对所有访谈生效，不含特定人名或话题的检索加分。

检索资格和论断归属分开：相关嘉宾陈述与相邻原稿可进入普通回答；立正自己的观点仍须自己的直接表达支持。单人投影命中后回到实际命中单元附近，不从原投影的第一条时间码跳转。模型最多读约2400字的相邻原文，公开摘录仍不超过500字；链接、时间码、片段ID和来源hash由服务器绑定。公开摘录另选相关的小窗口，不能截断模型用于理解的上下文。

来源在排序中按节目与窗口分层；同源窗口保持先后排名并受既有三窗口预算限制。语义候选在截断前限制同源重复，导航卡作为一条排名通道，按问题的实际词项覆盖保留具体话题。参数是检索默认，不改变来源事实或归属边界。

回答说明由全部模型共用。嘉宾的观点本身有参考价值，不以立正认可为前提。认可、限定、追问、反对要读具体上下文；邀请、发布、客套回应、剪辑中的相邻位置及一次局部认可不能推出全面背书。服务器固定原稿归属、窗口、编号和快照绑定；不再用自然语言正则给答案的归属关系一票否决。试验中旧正则反复误拦正确的否定、局部认可和文章中明确转述嘉宾的句子。它仅保留为离线诊断，不作为事实真伪评分。归属语义由共用回答合同和独立原文评审检验，不能把结构校验当作已经证明了意思。

验证包含：原稿／目录／质量与许可合同；原文单元及邻居字段防篡改；问题和回应不升级为立场；三个并发访谈查询的256MB容器内存；固定原文下的新旧版本重复回答与盲评。独立验收题从未出现在先前评测的六份访谈按固定hash排序抽取，再由原稿中段制题；在首次查询前冻结。标准答案引用固定原稿的连续单元ID，不在评测文件里复制大段原文。测试只能覆盖结构和部分效果，不代表线上准确率。

本轮完整模型输入、回答及评分只保存在忽略的本地目录 `.local/interview-revision-20261102/`；公开交付只保留可复核的方法、版本、结构化统计及必要的局限。既有公开回答是当时的快照，不自动重写。

并发验证发现共享SQLite连接的 execute/fetch 可交错，导致访谈检索返回500。现在数据库读取及共享词项缓存由重入锁保护；只串行化同一连接的读取，解压与排序仍在锁外，继续使用同一4MB页缓存。三个并发的真实访谈查询纳入镜像内存门禁。

逐段模型标注使用短方法标签，重复的方法解释集中在每份材料的说明中；确认归属的文字、次序和说话人均保留，公开摘录沿用易读标注。`/api/meta` 同时公开回答合同版本和与离线评测相同的代码指纹，部署核对不再只依赖资料版本或托管平台未提供的Git标识。

第一轮候选盲评在开发题发现：即使未确认段落标成“待定”，模型仍会把其中的数字、个人经历或回应接到相邻已知人物名下。因此最终证据接口把未确认段落的正文留在可追溯的原稿／公开摘录，回答模型只收到该位置的缺口标记；不能跨缺口补写发言或赞同。没有任何已确认陈述的原稿窗口只可发现，不作为普通回答依据。没有用推测补说话人，没有删除原稿，也没有按人名或话题设例外。保留确认的提问与回应，仍由模型解释具体关系。这是证据资格边界的修正；原候选诊断不能冒充最终版本结果。
