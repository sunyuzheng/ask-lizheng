## 回答质量检查

用六个预填问题，以及观点范围冲突、换说法、转行、AI 判断、未知嘉宾与世界杯赛果共十二个合成问题做真实模型检查。成功响应不等于理解正确，额外人工核对了核心结论、条件和出处。

学习问题能找到《假学习的终结》，而不是把作品完成当能力形成。工作价值问题将薪酬与流程作为可能解释，没有直接认定读者处境。自媒体问题比较目标与条件，没有把周洁案例变成所有人应该选择高变现的结论。Don't build 与学习项目的范围分别保留；良质回答标出哲学视角不构成形式证明。找内容返回可选择的阅读起点。世界杯问题返回 unsupported，未继续追问年份或承诺查询外部网站。

未知嘉宾问题首轮失败：模型将未检索到保证扩展成没有嘉宾作过保证，提示词修改仍未稳定纠正。最终加了人物归属前置检查：未指明人物／节目且没有其他背景时先返回 clarify，不调用模型；HTTP 实测及回归测试通过。这个检查不代替其他问题的语义事实核对。

多轮实测发现判断卡未沿用指代式追问的主题，已修复为只借用上一轮明确问题；新主题保持独立。随后检查“那我先试哪一步”的检索与回答，避免再次给完整流程。模型回答仍可能漏条件、误读片段；界面说明和原文入口允许读者继续核对。

首轮真实调用为 17.5–68.4 秒。这不是服务时延保证；前端提供阶段状态、20 秒后的等待说明和停止操作。生成与修复共用 85 秒预算，query embedding 共用 8 秒预算，失败保留原文入口。

## 界面实测

在 Codex 浏览器检查 1440、1280 和 375 像素宽度：首页、三个模式、可修改预填、选填背景、真实问答、原文展开、视频时间点、出处编号跳转、旧一轮出处、多轮追问、停止后保留问题及复制成功提示。说明弹窗支持 Escape 并恢复焦点。375 宽度没有水平溢出，出处在回答下方；宽屏提供右侧阅读栏。临时 viewport 已恢复默认。生产问答没有存入这些验收记录；测试使用合成输入。

## 首版上线验收

首版仓库 [CI](https://github.com/sunyuzheng/ask-lizheng/actions/runs/36803846576) 已通过 Python 3.12、Node 22、release validation、应用测试与 Linux Docker build。Builder 部署为 HEALTHY，health、metadata、search、真实问答及移动布局完成检查。平台没有返回构建 commit；通过发布前后远端 main SHA、资料锁与线上 JS/CSS 内容哈希确认部署版本。本机完整检索与索引验证进程峰值约 106.8 MiB。

## 速度与等待体验更新（本地候选版）

候选版默认模型改为 `grok-4-fast`。真实端到端合成请求中，候选材料在 0.171 / 0.194 秒出现；语义合并在约 1.4–1.5 秒完成。材料外的问题在 3.604 秒返回 unsupported，不提供问题或来源；观点范围问题在 8.139 秒完成，选择实际来源并保持不同用途的区别。浏览器学习题完成为两节，核心是能力迁移与一个小尝试；没有附加工程分层清单。上述是小样本，不能推断广泛质量或稳定时延。

模型对照揭示：GPT-5 默认流式仍需约 31.3 秒才返回内容，4000-token 预算下本次截断；low 模式一次在 24.0 秒完整生成，另一轮为 34.2 秒，但仍产生不必要的精确日程与工程框架。Grok 对照生成一次为 4.46 秒，内容较简洁；其对照输入为词法候选，不能与上述完整语义链路直接作速度比例比较。原始默认 GPT-5 的首版样本仍保留，不把提速当成正确性保证。

前端实际展示服务器查找、匹配、整理、格式与引用校验阶段，以及原文片段、模型名称、等待秒数、停止入口。候选明确标为未最终采用；停止或模型失败时仍保留材料。桌面与 375 像素手机预览通过，浏览器无控制台错误、无横向溢出。摘要限定 350 字符，段落最多三节。

候选版本项目 105 个测试通过，加上资料包 29 个为 134 个；前端 build 通过。独立审查复现了断线时异步清理再次取消导致并发额度泄漏，现已用同步 finally 释放，连续四次断线均恢复三个额度，provider 任务取消。新增 AnyIO 持续取消回归覆盖这个生产行为。首次本地来源在语义请求未完成时已经发出，也有延迟语义和停止清理的回归覆盖。

本次候选代码与模型配置尚未推送或部署；更新批准后须重新检查 CI、Builder 健康、真实 SSE 先出现 sources、实际默认模型及线上资产版本。

接口依据 [Builder OpenAPI](https://space.ai-builders.com/backend/openapi.json)。发布流程在运行环境与真实站点验证后才完成。
