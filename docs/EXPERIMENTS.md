# 付费实验的目的与停止条件

真实模型调用用于解决一个待决策的问题。不是不能花钱；投入应换来有用的判断，不能用调用量、测试轮数或分数表证明工作繁忙。

调用前，在私有实验记录中简述：

- 当前要决定什么，还缺哪一个信号。
- 什么结果会改变采用、拒绝或下一步行动。
- 能区分这些结果的最小验证，以及预估调用量和费用。
- 拿到什么信号就停止；什么新证据才值得扩大。

先复用已有输入、答案、向量和离线检查。修改评测脚本不等于必须重新生成答案；评审变化先用能暴露差异的记录核对，再判断是否需要扩大重评。多次采样只用于回答具体的波动问题，不默认全题集三轮。

扩大题集、延长模型上下文、提高并发或再跑一轮前，说明相对已有结果能多知道什么。结果不会改变决定，就不跑；已经获得足够信号，就完成交付。账户余额只表示可用额度，不是任务预算。费用记录保留在私有目录，不公开账户或账单信息。
